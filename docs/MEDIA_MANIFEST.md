## Adding approved media

1. Verify current implementation, attribution, rights and disclosure safety; do not use a public repository as blanket employer permission.
2. Copy the approved artifact under `public/media/`, create sensible resized versions and record its source here and in the caption.
3. Add a typed `MediaImage`/`MediaVideo` in the canonical project record. Include dimensions, alt, meaningful caption and source URL when public.
4. Videos require a real poster and description, must be muted/short/optimized, and need caption tracks when relevant spoken content remains. Do not add a fake URL simply to enable the control.
5. Rebuild, exercise desktop hover/focus and touch/manual playback, reduced motion, failed assets and slow-connection behavior. Runtime policy tests alone do not prove that an actual encoded video decodes correctly.
6. Preserve source/status distinctions; update this manifest and the content ledger before publication.

No light/dark media variants are currently justified. The schema and `<picture>` implementation support them when the same content genuinely needs a different exposure/background treatment.
